## UI screenshots

The screenshots in [`screenshots/`](screenshots/) are generated by the
Playwright E2E suite (`tests/ui/test_dashboard_e2e.py`) at a fixed 1440×900
viewport against the seeded Docker container. Regenerate with:

```bash
docker compose up --detach --force-recreate --wait
uv run pytest tests/ui -v --tb=short
```

See [`screenshots/README.md`](screenshots/README.md) for the file map.
