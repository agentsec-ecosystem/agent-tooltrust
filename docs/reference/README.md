## UI screenshots

The `ui-*.png` files in this directory are **generated by the Playwright E2E
suite** (`tests/ui/test_dashboard_e2e.py`) and captured at a fixed 1440×900
viewport for the user guides. They are regenerated on each release; do not
edit them by hand. See `docs/test/web-ui-test-plan.md` (§4.5) for the mapping
of page → screenshot and the surrounding capture workflow.
