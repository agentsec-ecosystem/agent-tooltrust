# Screenshots

Operator-console screenshots for the user guide. Regenerated by the Playwright
suite (`tests/ui/test_dashboard_e2e.py`) against the Docker container after
seeding demo data (`POST /api/seed`).

| File | View |
|------|------|
| `ui-dashboard.png` | Dashboard home (escalations, pending) |
| `ui-escalations-pending.png` | Pending escalations |
| `ui-escalations-all.png` | All escalation states (pending/approved/denied/expired) |
| `ui-audit.png` | Audit trail |
| `ui-sessions.png` | Session replay |
| `ui-analytics.png` | Analytics |
| `ui-baselines.png` | Security baselines |
| `ui-health.png` | Server health |

Regenerate with:

```bash
docker compose up --detach --force-recreate --wait
uv run pytest tests/ui -v --tb=short
```
